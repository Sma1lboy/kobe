Add three bundled themes — `gruvbox`, `catppuccin` (Mocha/Latte), and `rose-pine` (Main/Dawn) — bringing the built-in set to ten. Three more (`everforest`, `kanagawa`, `solarized`) are hosted on the landing site and install with `kobe theme add https://kobe.sma1lboy.me/themes/<name>.json`, as worked examples of the publish path. Every new theme defines both a dark and a light mode using its upstream project's published palette, and was checked so body text, muted text, selected-row text, and the state colors all clear WCAG contrast floors in both modes.
