Inbox RECENT is now ordered by where you actually were, not by what changed: landing on a tab records a visit (one entry per task, remembering the tab), and the section sorts by that log — a background mutation like a PR-status refresh no longer reshuffles it. Opening a recent row returns you to the tab you left, and a row whose engine is still working shows a quiet running pulse.
