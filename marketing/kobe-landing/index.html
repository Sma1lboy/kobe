The agent multiplexer in your shell.

One agent is a conversation. Five at once are a graph: nodes are isolated attempts — git worktree + engine session + branch — edges are dependencies, and the gates are your judgment. kobe is the terminal-native runtime for that graph.

The primitives

Fan out. Review. Land.

Every attempt is disposable until you merge it. Spawn parallel takes on the same prompt, keep the diff view honest, and land the winner — the losers evaporate with their worktrees.

01 fan out
$ kobe api fan-out --prompt "fix the flaky
  pty test" --engines claude,codex -n 4

Parallel attempts, isolated

Each node gets its own git worktree, branch and hosted engine session. No agent ever touches another's files.

Why terminal-native

Built where your code already lives.

isolation

Worktree per task

Attempts run in real git worktrees on real branches. Kill one, keep four — nothing bleeds.

engines

Claude + Codex, one contract

Engine adapters own identity, history and telemetry. Swap engines per task; the UI never hard-codes a vendor.

daemon

Survives your session

A refcounted daemon hosts engine PTYs. Close the TUI, reattach later — your agents kept working.

anywhere

SSH is the deploy story

Laptop, devbox, VPS. No browser, no VNC, no desktop app — if you can open a shell, you can run the fleet.

dashboard

Web board when you want it

A local web dashboard mirrors tasks, issues and diffs for the moments a mouse is faster.

keyboard

Chords, not menus

Pane-scoped keys, ctrl+t to spawn, ctrl+w to switch. Muscle memory is the interface.
