Questions

Before you ask.

Which AI builders do the prompts work with?

Claude, Cursor and Lovable are tested on every entry; Bolt and v0 work for most. The prompts describe design decisions, not tool commands — anything that writes front-end code from natural language will follow them.

Why do the prompts work when mine don't?

"Modern and clean" gives the model nothing to build. These prompts specify the things a senior designer decides by reflex — light temperature, easing curves, optical type sizes, blur radii, grain levels. Specific inputs, specific output.

Do I need to know how to code?

No. You copy, you paste, your builder writes the code. Knowing CSS only helps if you want to tune the result afterwards — each prompt names its own knobs so you can ask the AI to adjust them.

Can I use the output commercially?

Yes — client work, your own products, resale of the sites you build. The only thing you can't resell is the prompt library itself.
