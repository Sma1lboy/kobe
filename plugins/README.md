# First-party example plugins — moved

The official plugins now live in their own repo so it can carry the
`kobe-plugin` GitHub topic and appear in the marketplace automatically:

**https://github.com/Sma1lboy/kobe-plugins**

```bash
kobe plugin install Sma1lboy/kobe-plugins/notify
kobe plugin install Sma1lboy/kobe-plugins/github-start
kobe plugin install Sma1lboy/kobe-plugins/worktree-include
kobe plugin install Sma1lboy/kobe-plugins/linear-start
kobe plugin install Sma1lboy/kobe-plugins/lazygit
kobe plugin install Sma1lboy/kobe-plugins/browser
```

The copies in this directory are frozen at the migration point (2026-07-29)
and kept only until removal is confirmed; develop and install from the
dedicated repo.
